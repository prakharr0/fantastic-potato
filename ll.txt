🛠 Fix
Go to:
ExceptionGen.java:138
ComplexMath.riskyOperation()
You probably have something like:
Integer divisor = getDivisor();
return value / divisor;
Fix:
Option 1 — Null check
if (divisor == null) {
    throw new IllegalArgumentException("Divisor cannot be null");
}
Option 2 — Default value
int d = divisor == null ? 1 : divisor;
return value / d;
Option 3 — Fail early
Objects.requireNonNull(divisor, "Divisor must not be null");
